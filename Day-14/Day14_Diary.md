# Day 14 - Advanced DOM Manipulation

## Overview

The fourteenth day of the MERN Stack training focused on advanced DOM manipulation techniques using JavaScript. The session covered creating, inserting, removing, and replacing HTML elements dynamically, along with traversing the Document Object Model (DOM). These concepts help developers modify webpage content in real time, making web applications more interactive and user-friendly.

---

## Topics Covered

### 1. Creating HTML Elements

Studied how to create new HTML elements dynamically using JavaScript.

**Methods Covered:**

- `document.createElement()`
- `appendChild()`

These methods allow developers to generate new elements and insert them into the webpage dynamically.

---

### 2. Removing HTML Elements

Learned how to remove existing elements from the webpage.

**Method Covered:**

- `remove()`

This method is useful for deleting elements based on user actions or application requirements.

---

### 3. Replacing HTML Elements

Studied how to replace an existing HTML element with a newly created element.

**Method Covered:**

- `replaceChild()`

This method enables dynamic modification of webpage content without reloading the page.

---

### 4. DOM Traversing

Learned how to navigate through the DOM tree and access related HTML elements.

**Properties Covered:**

- `parentElement`
- `children`
- `firstElementChild`
- `lastElementChild`
- `nextElementSibling`
- `previousElementSibling`

These properties help establish relationships between different elements within a webpage.

---
