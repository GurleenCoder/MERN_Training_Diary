# Day 17 - Introduction to React and JSX

## Overview

The seventeenth day of the MERN Stack training marked the beginning of React.js, a popular JavaScript library used for building modern, fast, and interactive user interfaces. The session introduced the fundamentals of React, its advantages over traditional JavaScript, project setup using Vite, and JSX syntax. The concepts covered during this session form the foundation for developing single-page applications (SPAs).

---

## Topics Covered

### 1. Introduction to React

Studied React.js and understood its role in front-end web development. React enables developers to build reusable UI components, making applications easier to develop and maintain.

---

### 2. Features of React

Learned the key features of React, including:

- Component-Based Architecture
- Virtual DOM
- Declarative Programming
- Reusable Components
- One-Way Data Binding
- High Performance

These features make React efficient for developing dynamic web applications.

---

### 3. Why React?

Studied the advantages of using React over traditional JavaScript for building user interfaces.

Some advantages include:

- Faster rendering using Virtual DOM
- Reusable components
- Better code organization
- Easy maintenance
- Improved user experience

---

### 4. Installing React using Vite

Learned how to create a React project using Vite.

**Commands Practiced:**

```bash
npm create vite@latest
cd project-name
npm install
npm run dev
```

Also understood the purpose of Node.js and npm in React development.

---

### 5. React Project Structure

Explored the folder structure created by Vite.

Common files and folders studied include:

- `src`
- `public`
- `App.jsx`
- `main.jsx`
- `package.json`

Understood the purpose of each file within a React project.

---

### 6. JSX (JavaScript XML)

Studied JSX, a syntax extension for JavaScript that allows writing HTML-like code inside JavaScript.

Learned the basic rules of JSX, including:

- Returning a single parent element
- Using `className` instead of `class`
- Embedding JavaScript expressions using `{}`

---

### 7. Rendering React Application

Learned how React renders components into the browser using the root element and the `main.jsx` file.

---

## Task Assigned

No specific programming task was assigned during the session. The instructor encouraged us to create a React project using Vite, explore the project structure, and practice writing simple JSX code to understand how React applications are built and rendered.
