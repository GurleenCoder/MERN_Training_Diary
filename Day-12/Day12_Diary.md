# Day 12 - Objects in JavaScript

## Overview

The twelfth day of the MERN Stack training focused on JavaScript Objects and related concepts used for organizing, managing, and manipulating data efficiently. The session covered object creation, built-in object methods, the Math object, object cloning techniques and iteration using `for...in` and `for...of` loops. These concepts are essential for developing scalable and maintainable JavaScript applications.

---

## Topics Covered

### 1. Introduction to Objects

Studied JavaScript objects as collections of key-value pairs used to represent real-world entities and organize related data efficiently.

**Example:**

```javascript
let student = {
    name: "John",
    age: 20,
    course: "B.Tech"
};
```

---

### 2. Creating and Accessing Objects

Learned how to create objects and access their properties using different approaches.

**Methods Covered:**

- Dot Notation (`object.property`)
- Bracket Notation (`object["property"]`)

Also studied how to add, update, and delete object properties.

---

### 3. Object Methods

Explored commonly used built-in object methods for retrieving and manipulating object data.

**Methods Covered:**

- `Object.keys()`
- `Object.values()`
- `Object.entries()`
- `Object.assign()`
- `Object.freeze()`
- `Object.seal()`
- `hasOwnProperty()`

---

### 4. Math Object

Studied JavaScript's built-in `Math` object, which provides various mathematical properties and functions.

**Methods Covered:**

- `Math.round()`
- `Math.floor()`
- `Math.ceil()`
- `Math.trunc()`
- `Math.random()`
- `Math.max()`
- `Math.min()`
- `Math.pow()`
- `Math.sqrt()`
- `Math.abs()`

These methods are commonly used to perform mathematical calculations and generate random values in JavaScript.

---

### 5. Object Cloning

Learned different techniques for creating copies of objects.

**Types Covered:**

- Shallow Copy
- Deep Copy

Also understood the difference between copying an object reference and creating an independent copy of an object.

---



### 6. Iteration using `for...in` and `for...of`

Learned different looping constructs used for iterating over objects and iterable data structures.

**Loops Covered:**

- `for...in`
- `for...of`

Also understood the differences between the two loops and their appropriate use cases.

---

## Task Assigned
