# Day 13 - Document Object Model (DOM) Fundamentals

## Overview

The thirteenth day of the MERN Stack training focused on the fundamentals of the Document Object Model (DOM). The DOM represents an HTML document as a tree of objects that enables JavaScript to access, manipulate, and update webpage elements dynamically. The session introduced various DOM selector methods, content manipulation techniques, attribute handling, and dynamic styling using JavaScript. These concepts form the foundation for creating interactive and responsive web applications.

---

## Topics Covered

### 1. Introduction to DOM

Studied the Document Object Model (DOM) and understood how JavaScript interacts with HTML elements by treating them as objects. The DOM allows developers to dynamically modify webpage content without changing the original HTML source.

---

### 2. DOM Selectors

Learned different methods used to access HTML elements from the document.

**Selectors Covered:**

- `getElementById()`
- `getElementsByClassName()`
- `getElementsByTagName()`
- `querySelector()`
- `querySelectorAll()`

These methods help locate specific elements for further manipulation.

---

### 3. Content Manipulation

Studied different properties used to modify the content of HTML elements dynamically.

**Properties Covered:**

- `innerHTML`
- `innerText`
- `textContent`

These properties allow JavaScript to update webpage content according to user interactions or application requirements.

---

### 4. Working with Attributes

Learned how to access and modify HTML element attributes.

**Methods Covered:**

- `getAttribute()`
- `setAttribute()`
- `removeAttribute()`

These methods are commonly used to manipulate attributes such as `src`, `href`, `id`, `class`, and `width`.

---

### 5. Styling Elements using JavaScript

Studied how JavaScript can dynamically change the appearance of HTML elements.

**Concepts Covered:**

- `style` Property
- `classList`

These features allow developers to apply CSS styles and manage CSS classes programmatically.

---
