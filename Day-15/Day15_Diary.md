# Day 15 - JavaScript Event Listeners

## Overview

The fifteenth day of the MERN Stack training focused on JavaScript Event Listeners, an essential concept for developing interactive web applications. Event listeners enable JavaScript to detect and respond to user actions such as mouse clicks, keyboard input, and form interactions. The session introduced various types of events, the `addEventListener()` method, and practical implementation of event handling to create dynamic user interfaces.

---

## Topics Covered

### 1. Introduction to Events

Studied the concept of events in JavaScript and understood how user interactions trigger specific actions on a webpage.

Some common events include:

- `click`
- `dblclick`
- `mouseover`
- `mouseout`
- `keydown`
- `keyup`
- `submit`
- `change`

---

### 2. Event Listeners

Learned how to attach event listeners to HTML elements using the `addEventListener()` method.

**Syntax:**

```javascript
element.addEventListener("event", callbackFunction);
```

This method allows JavaScript to execute a specific function whenever a particular event occurs.

---

### 3. Mouse Events

Studied different mouse-related events that respond to user interactions.

**Events Covered:**

- `click`
- `dblclick`
- `mouseover`
- `mouseout`

These events are commonly used to build interactive user interfaces.

---

### 4. Keyboard Events

Learned how JavaScript responds to keyboard input.

**Events Covered:**

- `keydown`
- `keyup`

These events are useful for capturing user input and implementing keyboard-based functionality.

---

### 5. Form Events

Studied events associated with HTML forms.

**Events Covered:**

- `submit`
- `change`

These events help validate and process user input efficiently.
