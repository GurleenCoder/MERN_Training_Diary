# Day 20 - Introduction to Node.js

## Overview

The twentieth day of the MERN Stack training marked the beginning of back-end development with Node.js. The session introduced Node.js, its architecture, advantages, and how JavaScript can be executed outside the browser. The session also covered npm (Node Package Manager), Node.js modules, and the execution of JavaScript files using Node.js. These concepts form the foundation for developing server-side applications in the MERN Stack.

---

## Topics Covered

### 1. Introduction to Node.js

Studied Node.js, an open-source JavaScript runtime environment built on Chrome's V8 JavaScript Engine. Node.js allows developers to execute JavaScript outside the browser and build scalable server-side applications.

---

### 2. Features of Node.js

Learned the major features of Node.js, including:

- Asynchronous and Event-Driven
- Non-Blocking I/O
- Fast Execution using the V8 Engine
- Single-Threaded Architecture
- Cross-Platform Support
- Highly Scalable

These features make Node.js suitable for modern web application development.

---

### 3. Installing Node.js

Learned how to install Node.js and verify the installation using terminal commands.

**Commands Practiced:**

```bash
node -v
npm -v
```

These commands display the installed versions of Node.js and npm.

---

### 4. Node Package Manager (npm)

Studied npm, the default package manager for Node.js used to install, update, and manage project dependencies.

**Common Commands:**

```bash
npm init
npm install
npm uninstall
```

---

### 5. Running JavaScript using Node.js

Learned how to execute JavaScript files using the Node.js runtime.

**Command:**

```bash
node filename.js
```

---

### 6. Node.js Modules

Studied the concept of modules in Node.js and understood how code can be organized into separate files.

**Keywords Covered:**

- `require()`
- `module.exports`

Modules improve code organization and reusability.

---
